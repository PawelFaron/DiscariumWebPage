Discarium source code.

Discarium is licensed under the GNU General Public License, version 2 or later. Its source code and build instructions are maintained in the application repository.

Application repository ↗

The application’s software notices list the included libraries and their licenses. These include FFmpeg, libbluray, libudfread, libdvdnav, libdvdread, WavPack, AMSMB2 and libsmb2.

Corresponding source for your build.

Recipients of a Discarium build can obtain its corresponding source, including application code, dependency sources, modifications and build scripts. The exact package matters: the latest development branch may differ from the version installed on your Apple TV.

To obtain the package for your version, contact the developer with the version and build number shown in the app’s information screen.

discarium@pisz.to

Private signing keys, passwords, personal library indexes and commercial media are not part of the source package. The software license does not grant rights to unrelated media or trademarks.
